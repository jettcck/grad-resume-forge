## 四、踩坑清单（可复用的经验）

| 坑 | 教训 |
|---|---|
| `EL._internal` 只接受数组 children | 数据层测试全绿 ≠ 功能可用；UI 必须真实渲染验证 |
| `ELECTRON_RUN_AS_NODE` | 命令"跑完了但什么都没发生"时，先怀疑环境变量 |
| `curl` 访问 127.0.0.1 被代理拦截 | `NO_PROXY` 为空时加 `--noproxy '*'` |
| Ollama blob 中断不续传 | 长任务必须在单条命令内完成 |
| 按 y 聚行 ≠ 分栏正确 | 这是两个独立问题，必须分别解决 |
| 整页中缝检测被顶部通栏破坏 | 改用「垂直空白覆盖率」而非「有无字形」 |
| 右侧日期列被当第二栏 | 加「两侧字量 ≥ 25%」判据 |
| `printToPDF` 靠溢出分页不可靠 | 用显式 `page-break-after` |
| commit message 里的反引号被 shell 执行 | 含命令片段的 message 一律 `git commit -F` |
| 断言写死样本数据 | 加样本就误报，应按样本取值 |

**一条反复验证的规律**：每加一种排版样本，都会暴露一个在上一种排版上测不到的 bug。
单栏 → 双栏 → 侧边栏 → 表格 → 多页，五种样本才覆盖到现在的健壮度。
